App name: **PortTracker AIS**

Short description:

Receive AIS with a USB SDR and view nearby vessel traffic on your Android device.

Full description:

Turn a compatible Android device and USB SDR receiver into an AIS receiving station.

PortTracker AIS displays received vessel traffic on a map and provides a local web interface for station settings and diagnostics. Forward received AIS messages to compatible network applications using UDP or TCP, or configure MQTT output for your station.

Features include:
- USB SDR reception with supported RTL-SDR, AirSpy and AirSpy HF+ hardware.
- Vessel map, receiver status, message stream and diagnostic information.
- Configurable network output for compatible AIS applications.
- Optional local vessel database and position history.
- Optional phone location forwarding, with permission.

A compatible USB receiver, suitable antenna and USB host/OTG connection are required for radio reception. The phone alone does not receive AIS radio signals. Reception depends on hardware, antenna placement and local conditions. Internet access is needed for online map tiles and online services.

AIS data may be incomplete or delayed. Do not rely on this app as your sole source of navigation information.
